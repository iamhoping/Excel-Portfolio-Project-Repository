# Bike Sales Performance Dashboard
### FileName
- Excel Project Dataset.xlsx
## Description
A dynamic, interactive Excel dashboard designed to analyze customer demographics and purchasing behavior for a retail bike company. This project transforms raw data into actionable insights to help optimize marketing strategies and targeted sales campaigns.
<p align="center"> <img src="Screenshot 2026-05-29 142928.png" width="850" alt="Student Productivity Dashboard"> </p>

## Key Features & Analysis
- Dynamic KPI Metrics: Tracks total sales, conversion rates, customer volume, and average buyer income in real-time.
- Demographic Breakdown: Visualizes purchasing trends across gender, age brackets, and formal education levels.
- Behavioral Insights: Evaluates how income levels and daily commute distances directly impact a customer's likelihood to buy a bike.
- Interactive UI: Built using advanced Excel features including Pivot Tables, custom Pivot Charts, and synchronized Slicers for seamless data filtering.
