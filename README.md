# Power-Queries-and-Dashboard
This project is an end-to-end data solution designed to streamline inventory management and sales tracking for a hardware retail and warehouse environment. By leveraging Power Query for automated ETL (Extract, Transform, Load) processes, the system converts raw transactional data into actionable business intelligence.
